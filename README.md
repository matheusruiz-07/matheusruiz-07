## Sobre mim

Sou estudante de **Análise e Desenvolvimento de Sistemas na FIAP**, com foco em desenvolvimento back-end. Construo projetos acadêmicos envolvendo **Java, Python, SQL, bancos de dados relacionais, APIs REST e DDD**.

- 🔎 Busco uma oportunidade de **estágio em desenvolvimento back-end**

- ⚙️ Automatizo processos com **n8n** e trabalho com **Git/GitHub, pull requests, code review e CI/CD**
- 🧩 Também utilizo **React, TypeScript, HTML, CSS, Vite e Tailwind** em interfaces
